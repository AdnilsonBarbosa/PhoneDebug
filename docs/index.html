Phone Debug

Plug in an Android phone and see it on your PC. Control it with your mouse and keyboard - no typing on the phone, no cable juggling.

Download for Windows All releases Source code

or grab just the console tool: phone-debug.exe

Install

  1. Download the release zip from the button above and unzip it.
  2. Run install.ps1
  3. Reopen the terminal and run
    phone-debug

How it works

Plug & mirror

When you connect a phone, the screen opens automatically. Unplug and it goes back to waiting.

Wireless (Wi-Fi)

No cable needed. The QR pairing screen connects you over your Wi-Fi network.

Stubborn phones

Phones that ignore normal input (Xiaomi, POCO, Redmi) are controlled with an emulated USB keyboard and mouse. Automatic.

Two front ends

The same engine behind a command line and a small Windows app. Pick whichever you like.

Capabilities

  • Auto-detection with model, Android version and serial
  • Full mouse and keyboard control of the mirrored screen
  • Install APKs, take screenshots, stream the log
  • One device shown once, even if it shows up via USB and Wi-Fi
  • Per-user install, no administrator rights
