Barely two steps from plugging in

Phone Debug finds your phone, asks you to trust it once, and opens the screen. Everything else is automatic.

1 Download and unzip

Grab the release zip and extract it anywhere. The first run downloads adb and scrcpy into the tools folder for you - nothing to install system-wide.

2 Enable USB debugging

Settings > About phone > tap Build number 7 times, then Developer options > USB debugging. Phone Debug guides you through it if you get stuck.

3 Connect and mirror

Plug in the cable, or pair over Wi-Fi with a QR code. The screen opens by itself, and unplugging sends it back to waiting.

Questions, answered

Do I need to install adb or scrcpy?

No. Phone Debug downloads the current official builds into its tools folder on first run - from Google and GitHub, straight onto your machine. Set $env:PHONEDEBUG_NO_DOWNLOAD = "1" before starting if you'd rather supply them yourself.

Does it need administrator rights?

No. Everything is installed for the current user only - the app, its tools and the Start Menu entry. Nothing system-wide changes.

What about phones that block screen control?

Some makers (Xiaomi, POCO, Redmi) refuse normal injected input. Phone Debug notices and reopens the mirror as an emulated USB keyboard and mouse, which those phones accept. If it still won't respond, enable USB debugging (Security settings) and reboot the phone.

Can I connect over Wi-Fi?

Yes. phone-debug connect walks you through USB or Wi-Fi pairing. For Wi-Fi it prints a QR code in the terminal (or app) that you scan from the phone - no cable involved after that.

Windows says the download is "insecure" - is it safe?

That is SmartScreen / Edge blocking any brand-new executable that has no code-signing certificate yet. The files are the official builds from this repository. To keep them: choose More info then Run anyway (Edge) or Keep (Chrome) on the download. After a few people do this, Windows learns to trust them. Every release also carries a SHA256SUMS.txt and signed build provenance, so you can verify the files are exactly what the project shipped.

What does this cost?

Nothing. Phone Debug is MIT licensed, and the whole project is on GitHub. Releases carry signed build provenance you can verify.
